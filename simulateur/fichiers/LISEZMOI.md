# Fichiers déposés à la main

Certains sites (tennis-data.co.uk, aussportsbetting.com) refusent les téléchargements depuis les serveurs de GitHub.
Télécharge leurs fichiers `.xlsx` depuis ton navigateur, puis dépose-les ici : **Add file → Upload files**.

- Le nom des fichiers n'a pas d'importance : `2024.xlsx`, `2024 (1).xlsx`… le script reconnaît le tennis ATP ou WTA
  et l'année d'après le contenu. Seuls les fichiers de sports US doivent garder leur nom d'origine (`nba.xlsx`, `nfl.xlsx`…).
- Dès que tu déposes des fichiers, GitHub relance « Simulateur · matchs passés » tout seul et met à jour
  `simulateur/data/historique.js` (environ 15 minutes).
- Les fichiers restent ici : les mises à jour mensuelles les relisent. Pour ajouter les nouveaux matchs de l'année,
  re-télécharge le fichier de l'année en cours et dépose-le à nouveau (il remplace l'ancien s'il a le même nom).

Liens de téléchargement :
- Tennis ATP : `https://www.tennis-data.co.uk/ANNÉE/ANNÉE.xlsx` (ex. https://www.tennis-data.co.uk/2024/2024.xlsx)
- Tennis WTA : `https://www.tennis-data.co.uk/ANNÉEw/ANNÉE.xlsx` (ex. https://www.tennis-data.co.uk/2024w/2024.xlsx)
- Sports US / Australie : https://www.aussportsbetting.com/historical_data/nba.xlsx (même chose avec nfl, nhl, mlb, afl, nrl)
