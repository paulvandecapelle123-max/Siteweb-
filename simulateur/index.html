Le moteur IA n'a pas encore tourné

Toutes les heures, il repère les favoris à 97 % ou plus dans tous les sports pariables en ligne (football, tennis, basket, hockey, baseball, MMA, boxe, rugby, cricket…) et les met en surveillance. Environ une heure avant chaque match, Claude fait une dernière recherche sur internet (composition, blessures, forfaits, problèmes personnels, enjeu) et décide de parier ou non, en argent fictif. Pour l'activer :

  1. Crée une clé sur the-odds-api.com (cotes de dizaines de sports et de bookmakers). L'offre gratuite suffit pour tester ; pour surveiller tous les sports en continu, il faut l'offre payante.
  2. Facultatif : une clé API Claude sur console.anthropic.com, payante à l'usage (de quelques centimes à quelques dollars par jour ; mets une limite de dépense). Sans elle, le moteur est gratuit : il parie d'après les cotes seulement, sans recherches, et uniquement dans les sports dont les résultats arrivent automatiquement.
  3. Sur GitHub : ton dépôt → Settings → Secrets and variables → Actions → ajoute ODDS_API_KEY (et ANTHROPIC_API_KEY si tu as pris la clé Claude).
  4. Onglet Actions → « Simulateur · moteur IA (toutes les heures) » → Run workflow. Ensuite il tourne seul toutes les heures.
